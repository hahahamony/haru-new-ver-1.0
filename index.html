🤖 안드로이드 .APK 설치파일 만들기

APK 빌더

아래 버튼으로 앱 소스파일(index.html)과 전용 아이콘(icon.png)을 다운로드한 뒤, 무료 변환 도구에 넣으면 즉시 .apk 설치 파일이 생성됩니다.

⚡ 1분 만에 .APK 파일 생성하는 방법 (무료/무설치)
  1. 위 [1. index.html 저장]과 [2. 앱 아이콘]을 클릭해 다운로드합니다.
  2. 무료 웹→APK 변환 사이트(예: WebIntoApp.com 또는 AppsGeyser )에 접속합니다.
  3. HTML 파일 업로드 모드를 선택하고 방금 받은 index.html과 아이콘을 등록합니다.
  4. 앱 이름에 하루가계부를 입력하고 Make App (.APK) 버튼을 누르면 안드로이드 설치용 .apk 파일이 즉시 완성됩니다!
